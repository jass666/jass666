Role-based auth, dual SQLite/PostgreSQL backend, Google Sheets writeback, Meta webhook + Instagram Insights integration, APScheduler automation pipeline, canonical lead/media ID systems, and peer sync between a local Windows instance and a Render deployment. *(Private — proprietary business tool; happy to walk through the architecture.)*
